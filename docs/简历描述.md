# 简历描述草稿（只含真实做出的数字）

**项目名：英超赛事胜平负概率预测（Python / Streamlit）**

中文版（任选 2–3 条）：
1. 基于 football-data.co.uk 10 个赛季（约 4,000 场）英超数据，搭建基线、Elo 评分、泊松进球三层模型，并用「仅用比赛日前数据」的按时间滚动回测评估 3,140 场样本，杜绝未来信息泄露。
2. 以 log-loss、Brier 分数、准确率和校准曲线对比博彩赔率隐含概率：Elo 模型 log-loss 0.978、准确率 53.6%，较历史频率基线（1.067、43.9%）显著改善，但仍不及赔率（0.961、54.8%），并用 bootstrap 区间验证差距非偶然，如实报告。
3. 用 Streamlit 构建可交互网页（选赛季/轮次查看每场胜平负概率、近期状态、回测与校准图），并撰写方法说明，明确模型局限与「仅供学习研究」声明。

English:
- Built baseline, Elo and Poisson goal models on ~4,000 Premier League matches (10 seasons); evaluated 3,140 matches with a strictly time-rolling backtest (no look-ahead), with hyperparameters tuned on a separate season.
- Benchmarked against bookmaker-implied probabilities using log-loss, Brier score, accuracy and calibration curves: Elo reached log-loss 0.978 / 53.6% accuracy vs 1.067 / 43.9% for the base-rate baseline, but did not beat bookmaker odds (0.961 / 54.8%); reported honestly with bootstrap confidence intervals.
- Delivered an interactive Streamlit app and a methods note documenting limitations.

面试提醒：被问到「为什么没跑赢赔率」，答：赔率汇集了伤病、阵容等我们没有的信息，是很强的对照；项目价值在于严谨的评估流程和如实报告。
